# zomato-Niyaz

A full-stack food-ordering application: a React + TypeScript front end and a Spring Boot REST API with
JWT authentication, backed by MySQL.

**Front-end demo:** https://zomato-niyaz.vercel.app/ — see [What the hosted demo covers](#what-the-hosted-demo-covers).

## Stack

| Layer | Technology |
|---|---|
| Front end | React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, React Router, axios |
| Back end | Java 17, Spring Boot 3.2, Spring Web, Spring Data JPA, Spring Security, JWT (jjwt) |
| Database | MySQL 8 (schema generated by Hibernate, `ddl-auto=update`) |

## Repository layout

```
backend/    Spring Boot API (controllers, entities, JWT security)
frontend/   React app (pages, components, API client)
docs/       Design notes written during development (flows, schema, testing guide)
```

## What is implemented

- **Front end:** restaurant browsing with search, cuisine and rating filters; restaurant detail with menu;
  cart; checkout and payment pages; order history and tracking pages; favorites; reviews; address
  management; sign-up, login and password-reset screens; light/dark theme; PWA manifest.
- **API:** sign-up and login issuing JWTs (`/api/auth/**`), plus restaurant, review, order and user/address
  endpoints. Apart from `/api/auth/**`, the `public/` routes and the API-docs paths, requests require a
  valid token.
- **Roles:** `USER`, `RESTAURANT`, `DELIVERY_PARTNER`, `ADMIN`. Order endpoints are guarded with
  method-level `@PreAuthorize` rules.
- **Data model:** users, addresses, restaurants, menu categories and items, orders with items and status
  history, payments, delivery partners and earnings, reviews, subscriptions
  (see [docs/DATABASE_SCHEMA.md](docs/DATABASE_SCHEMA.md)).

## What the hosted demo covers

The Vercel deployment is the **front end only**. Restaurant and menu data on the browsing pages come from
sample data bundled in `frontend/src/data/data.js`. Sign-up, login, addresses, reviews and orders call the
Spring Boot API, which is not hosted, so those flows need the local setup below.

## Run it locally

**Prerequisites:** JDK 17, Maven 3.9+, Node 18+, MySQL 8.

1. Create the database:
   ```sql
   CREATE DATABASE zomato_db;
   ```
2. Set the backend environment variables (see [`.env.example`](.env.example)). The API will not start
   without a password and a JWT secret, because no secrets are stored in the repository:
   ```bash
   export SPRING_DATASOURCE_PASSWORD=<your mysql password>
   export APP_JWT_SECRET=$(openssl rand -base64 48)   # the secret is Base64-decoded by the app
   ```
   `SPRING_DATASOURCE_URL` and `SPRING_DATASOURCE_USERNAME` default to `localhost:3306/zomato_db` and `root`.
3. Start the API on port 8080:
   ```bash
   cd backend
   mvn spring-boot:run
   ```
4. Start the front end (Vite dev server):
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   The client talks to `http://localhost:8080/api` by default; override it with `VITE_API_URL` in
   `frontend/.env.local`.
